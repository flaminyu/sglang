Key Findings

1. TTL Priority Scheduling

TTL-pinned programs receive priority in scheduling, allowing them to bypass the queue and complete faster. This results in an average JCT improvement of 91.6% for TTL requests.

2. Queue Delay Reduction

TTL requests experience zero queue delay on average, while non-TTL requests face significant queue wait times. This is the primary benefit of TTL priority scheduling.

3. Trade-off

While TTL requests benefit from priority scheduling, non-TTL requests may experience slightly longer JCT due to being preempted. However, the overall system performance remains comparable.

4. Duration (Total Time)

Total simulation duration remains nearly identical between Baseline and TTL modes because:

  • GPU utilization stays at 100% (always processing requests)
  • Each request's processing time is the same
  • Only the order of completion changes
